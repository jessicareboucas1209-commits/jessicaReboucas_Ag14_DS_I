# 🏛️ Atrativos Turísticos de Lençóis Paulista

Uma página web moderna, limpa e responsiva desenvolvida para apresentar os principais pontos turísticos e culturais da cidade de Lençóis Paulista - SP. 

Este projeto foi construído como parte das atividades práticas do curso técnico de Desenvolvimento de Sistemas (**EaDTEC / Centro Paula Souza**), com foco na implementação de layouts estruturados, folhas de estilo e design responsivo.

---

## 🚀 Tecnologias Utilizadas

O projeto utiliza tecnologias web padrão de mercado e foco em performance e estilização ágil:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Customizações específicas para tratamento de imagens (`object-fit`) e espaçamentos.
* **W3.CSS (Framework):** Utilizado para a criação do sistema de Grid responsivo, estilização moderna dos cards (efeito *Paper Shadow*) e animações de opacidade na carga da página.

---

## 🎨 Características do Projeto

* **Layout em Cards:** Cada atrativo turístico possui seu próprio bloco visual contendo título destacado, imagem adaptada, descrição textual e dados informativos (localização e telefone).
* **Grid Responsivo:** O layout se adapta automaticamente ao tamanho da tela do usuário:
    * **Telas Grandes (Desktop):** Exibe 3 colunas por linha.
    * **Telas Médias (Tablets):** Exibe 2 colunas por linha.
    * **Telas Pequenas (Smartphones):** Exibe 1 coluna (cards empilhados), garantindo a melhor legibilidade.
* **Imagens Inteligentes:** Uso de técnicas de CSS para garantir que todas as fotos fiquem uniformes e sem distorções visuais no cabeçalho dos blocos.
